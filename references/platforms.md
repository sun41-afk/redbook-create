# 跨平台改编

先复用同一证据表，再按阅读方式改编。不因换平台改变研究结论。下列是编辑建议，不是流量承诺；平台功能或发布规则需要用到时查最新官方说明。

| 平台 | 建议形态 | 从小红书稿怎样改 |
|---|---|---|
| 小红书 | 3:4图文主稿 | 封面问句、证据概览、分主题展开 |
| 公众号 | 图文长文与系列目录 | 将页面文字转为连续段落，机制图穿插，补充可用的完整引用 |
| 知乎 | 针对具体问题的回答 | 开头直接回答，再展开研究、机制、适用条件，插入2–3张关键图 |
| 抖音 | 场景图集，或配旁白的短视频 | 一篇拆成一个明确问题，每屏一个要点，减少密集文献文字，保留简洁来源 |

默认先把主平台稳定下来，再试一个副平台。若目标是沉淀系列与读者关系，可优先公众号；若目标是回答搜索问题，可选知乎。抖音值得测试，但应单独制作更简洁的图集或旁白，不把密集8页直接视作最佳方案。

复盘记录平台、链接、发布时间、阅读量、收藏量、关注增量、相关评论与制作耗时。衡量每小时制作带来的有效反馈，不单看播放量。只有用户要求跨平台改编时才生成多份；制作内容不自动授权外部发布。

官方参考：
- [抖音发布能力使用规范](https://developer.open-douyin.com/docs/resource/zh-CN/dop/operation-standard/platform-capabilities/useclue)：开放能力支持图文和视频；该接入规范鼓励图集/视频，避免纯文字截图。不要把SDK接入条件当作所有普通创作者的注册门槛。
- [知乎创作者手册](https://www.zhihu.com/knowledge-plan/manual)：问答、文章等形态与创作建议。
